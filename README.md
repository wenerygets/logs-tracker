# 📊 Logs Tracker — Система учёта логов

Система для ведения учёта логов с разделением по воркерам. Telegram бот для быстрого добавления + веб-интерфейс для просмотра и аналитики.

## 🎯 Концепция

- **Воркер** — член команды, которому принадлежат логи
- **Лог** — запись с данными: пин, баланс, дата установки, дата проверки, тег, комментарий
- **Проверки** — система напоминаний по дате пополнения

## ✨ Возможности

### Telegram Бот
- ➕ Быстрое добавление логов через диалог
- 👥 Управление воркерами
- 📋 Просмотр логов по воркерам
- 📊 Статистика по тегам и воркерам
- 🔔 Проверки на сегодня
- 🔍 Поиск по пину

### Веб-интерфейс
- 🏠 Dashboard со статистикой
- 📋 Таблица логов с фильтрами
- 👥 Управление воркерами
- 🔔 Календарь проверок
- ✏️ Редактирование и удаление

## 📦 Установка

### 1. Установка зависимостей

```bash
cd backend
pip install -r requirements.txt
```

### 2. Настройка

Создайте файл `backend/.env`:

```env
# Получите у @BotFather в Telegram
BOT_TOKEN=ваш_токен_бота

# URL API (для бота)
API_URL=http://localhost:8000
```

### 3. Запуск сервера

```bash
cd backend
python main.py
```

Веб-интерфейс: http://localhost:8000

### 4. Запуск бота

В отдельном терминале:

```bash
cd backend
python bot.py
```

## 🔧 API

### Воркеры

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/workers` | Список воркеров |
| GET | `/api/workers/{id}` | Воркер по ID |
| POST | `/api/workers` | Создать воркера |
| PUT | `/api/workers/{id}` | Обновить воркера |
| DELETE | `/api/workers/{id}` | Удалить воркера |

### Логи

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/logs` | Список логов |
| GET | `/api/logs/{id}` | Лог по ID |
| POST | `/api/logs` | Создать лог |
| PUT | `/api/logs/{id}` | Обновить лог |
| DELETE | `/api/logs/{id}` | Удалить лог |

### Проверки и статистика

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/reminders?days=7` | Проверки на N дней |
| GET | `/api/reminders/today` | Проверки на сегодня |
| GET | `/api/stats` | Общая статистика |

### Фильтры `/api/logs`

- `worker_id` — ID воркера
- `tag` — Тег (fat, poor, medium, salary)
- `search` — Поиск по пину/комментарию
- `date_from`, `date_to` — Даты
- `sort_by`, `sort_order` — Сортировка
